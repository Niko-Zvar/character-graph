# Граф персонажей (Character Graph)

## Цель

Веб-сервис, который по тексту художественного произведения и списку персонажей строит граф их связей: кто с кем появляется в одном предложении или абзаце. Имена сравниваются с учётом падежей: «Ивану» и «Иван» считаются одним словом.

## Функционал

- Анализ текста, вставленного на веб-странице или загруженного TXT-файлом (UTF-8 или Windows-1251).
- Поиск персонажей по списку с вариантами имени (`Иван, Иван-царевич, Ванюша`).
- Подсчёт упоминаний персонажей и связей между ними.
- Результат на странице: граф-картинка и таблицы; через API (`POST /api/analyze`) — JSON.
- Проверка входных данных с сообщениями об ошибках.

## Установка

Нужны Git и [uv](https://docs.astral.sh/uv/getting-started/installation/).

```powershell
git clone https://github.com/<логин>/character-graph.git
cd character-graph
uv sync
```

## Настройки

| Параметр | Описание | По умолчанию |
|---|---|---|
| `text` | Текст произведения, до 3 000 000 символов | обязательно |
| `characters` | Персонажи и варианты имени, хотя бы один | обязательно |
| `window` | Фрагмент: `sentence` (предложение) или `paragraph` (абзац) | `sentence` |
| `min_mentions` | Минимум упоминаний персонажа | `1` |
| `min_links` | Минимальный вес связи | `1` |
| `top` | Показать только N самых упоминаемых персонажей | все |

Упоминание — фрагмент, где есть персонаж. Вес связи — число фрагментов, где два персонажа встречаются вместе.

## Пример входа и результата

Запрос `data/example_request.json`:

```json
{
  "text": "Иван встретил Василису Премудрую. Василиса рассказала Ивану про Кощея. Кощей прятался в лесу.",
  "characters": {
    "Иван": ["Иван-царевич", "Ванюша"],
    "Василиса": ["Василиса Премудрая"],
    "Кощей": []
  }
}
```

Результат:

```json
{
  "fragments": 3,
  "characters": {"Василиса": 2, "Иван": 2, "Кощей": 2},
  "links": [
    {"source": "Василиса", "target": "Иван", "weight": 2},
    {"source": "Василиса", "target": "Кощей", "weight": 1},
    {"source": "Иван", "target": "Кощей", "weight": 1}
  ]
}
```

## Ограничения

- Связь означает только появление в одном фрагменте, а не взаимодействие: в примере Василиса и Кощей связаны, хотя не встречаются.
- Учитываются только имена из списка; местоимения («он», «я») и описания («старуха») — нет.
- Сокращения вроде «т. е.» могут разбить предложение на два.
- Только русский язык.
