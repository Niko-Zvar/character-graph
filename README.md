# Граф персонажей (Character Graph)

Программа анализирует художественный текст, находит в нём персонажей и строит граф их связей: кто с кем чаще появляется рядом. Так видно, кто главный герой, какие персонажи образуют группы и кто связывает разные сюжетные линии.

## Цель программы

Помочь читателю и исследователю литературы увидеть структуру системы персонажей произведения. Вместо того чтобы вручную выписывать, кто с кем встречается, пользователь получает таблицу и наглядный граф.

## Ожидаемый вход

**Текст произведения**: TXT-файл в кодировке UTF-8.
**Список персонажей** (опционально): TXT-файл, где каждая строка — один персонаж.
**Параметры анализа** (см. раздел «Возможности параметризации»).

## Планируемый выход

**Таблица персонажей**: имя и число упоминаний (вывод в консоль и CSV-файл).
**Таблица связей**: пары персонажей и число их совместных появлений (CSV-файл).
**Изображение графа**: вершины — персонажи (чем чаще упоминается, тем крупнее), рёбра — связи (чем чаще персонажи рядом, тем толще линия).

## Базовый функционал

1. Чтение текстового файла и проверка, что он существует и не пуст.
2. Разбиение текста на фрагменты (предложения или абзацы).
3. Поиск упоминаний персонажей с учётом падежных форм (лемматизация через pymorphy3).
4. Объединение вариантов имени одного персонажа по списку персонажей.
5. Подсчёт упоминаний каждого персонажа.
6. Подсчёт совместных появлений: два персонажа связаны, если упомянуты в одном фрагменте.
7. Построение графа и сохранение его в виде изображения.
8. Сохранение таблиц с результатами в CSV.
9. Запись основных событий и ошибок в журнал (logging).

## Возможности параметризации

| Параметр | Описание | Значение по умолчанию |
|---|---|---|
| `--window` | Размер фрагмента, внутри которого персонажи считаются связанными: `sentence` (предложение) или `paragraph` (абзац) | `sentence` |
| `--min-mentions` | Минимальное число упоминаний, чтобы персонаж попал в граф | `2` |
| `--min-links` | Минимальное число совместных появлений, чтобы связь попала в граф | `1` |
| `--characters` | Путь к файлу со списком персонажей | не задан |
| `--output` | Папка для сохранения результатов | `results/` |
| `--top` | Показать в графе только N самых частых персонажей | все |
